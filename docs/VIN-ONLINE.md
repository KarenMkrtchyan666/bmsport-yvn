# Автозаполнение VIN: локальный и бесплатный онлайн-поиск

## Порядок определения

После ввода полного VIN форма автоматически заполняет марку, модель, модификацию и доступные сведения о кузове. Для BMW/MINI/Rolls-Royce сначала используется локальный каталог заводских типовых кодов. Затем проверяется однозначное совпадение в собственной истории. Если этих данных нет, запрос последовательно проходит бесплатные онлайн-источники до получения марки, модели и типа кузова.

Введённый VIN нормализуется: 17 букв/цифр, без I/O/Q. Правки марки, модели и автомобиля, внесённые во время поиска, не затираются; старые и отменённые ответы не применяются. Неполный VIN не блокирует ручное сохранение посещения.

Сохранение ожидает начатый поиск. Тип кузова (`bodyStyle`), модельный год (`modelYear`) и источник (`vinSource`) сохраняются в JSON посещения; старые записи совместимы. Тип кузова и год отображаются в форме и PDF. Ручная корректировка автомобиля снимает указание VIN-источника с изменённых данных.

## Подключённые бесплатные API

Все пять проверены на публичном примере VIN из документации; аккаунт, ключ и оплата не требуются.

| Источник | Роль | Условия |
|---|---|---|
| [NHTSA vPIC](https://vpic.nhtsa.dot.gov/api/) | Основной онлайн-декодер, `DecodeVinValuesExtended` | Бесплатный публичный API; серверное ограничение трафика |
| [VinSpecs](https://vinspecs.org/api) | Резерв | 100 запросов/час/IP; видимая атрибуция |
| [CleanVins](https://www.cleanvins.com/developers) | Резерв | Примерно 60 запросов/мин/IP; атрибуция |
| [CheckMyVIN](https://checkmyvin.net/docs/api) | Резерв | 100 запросов/IP/сутки; `POST /api/decode` |
| [CarWhere](https://www.carwhere.com/developers/vin-api) | Резерв | Fair use; видимая ссылка Powered by CarWhere |

Резервные источники в основном используют NHTSA: это дополнительные способы доступа и кеширования, а не независимое подтверждение и не увеличение географического охвата в пять раз. AI-тексты, цены, рекламные ссылки и платные отчёты из ответов не используются.

При полном результате дальнейшие источники не вызываются. Положительные результаты хранятся в оперативной памяти до 24 часов, подтверждённое отсутствие — 10 минут, максимум 500 записей. Параллельные одинаковые VIN объединяются. Ошибки сети не кешируются как отсутствие автомобиля. На источник отводится до 4 секунд, общий бюджет — до 18 секунд. HTTP 429 включает паузу с учётом `Retry-After`.

Данные требуют проверки по автомобилю. Марка/модель/тип кузова принимаются из полей ответа; заводской код вроде E90 по году и слову «седан» не угадывается. Несовпадение VIN в ответе или сообщение об исправленном/небезопасно декодированном VIN отменяет автоподстановку. Несовпадение контрольной цифры показывается предупреждением.

Сервисы со свободным тарифом, но требующие регистрации/API-ключа (например [Auto.dev](https://docs.auto.dev/v2/getting-started)), не активированы. Это не означает, что абсолютно все сайты с бесплатной формой VIN предоставляют свободный API.

## Передаваемые данные

По прямому запросу пользователя подключён внешний VIN-поиск. Провайдерам передаётся только сам VIN, без имени клиента, номера телефона, PDF диагностики, истории посещений и заметок. Для известных локальных совпадений внешних запросов нет. VIN не выводится в журналы приложения. Ссылки на использованные источники отображаются рядом с результатом и сохраняются в PDF при использовании их данных.

## Локальный справочник

[BimmerArchive Open Data](https://github.com/alisacorporation/bimmerarchive-open-data): 4 339 заводских типовых кодов. Атрибуция и ограничения сохранены в `assets/vin/DATA.md`, лицензия — в `assets/vin/LICENSE.txt`. Это справочная, не официальная база BMW; охват неполный. Тип сопоставляется с символами 4–7 VIN только для известных WMI марки. Каталог не подтверждает подлинность VIN или комплектацию экземпляра.

## Проверки

`npm test`: пять форматов API, резервирование, кеш, лимиты, ошибки сети, отсутствие результата, исправленные/чужие VIN, локальные совпадения и история. У сетевых тестов подставлены ответы — клиентские VIN и данные не используются. `node scripts/vin-browser-check.mjs`: автозаполнение, смена VIN, ручные правки, онлайн-атрибуция, сохранение и загрузка типа кузова/года. `npm run test:browser`: форма, диагностика и экспорт PDF.

Служебный список активных источников: `GET /api/vin/sources`. Определение: `POST /api/vin/decode`.

### Европейский VIN и неполное покрытие NHTSA

Коды NHTSA `1,5,14` могут означать, что американская база не знает европейский формат. Они не доказывают ошибку ввода. Неподтверждённые поля такого ответа пропускаются, но поиск продолжается через остальные источники. Если все базы не справились, показывается нейтральное сообщение об ограничении покрытия, без утверждения «VIN неверный».

Для Mercedes-Benz добавлен локальный справочник заводских типов из первичных архивных источников; первая подтверждённая запись `203.035` соответствует `C 180`, кузов `W203`: https://mercedes-benz-archive.com/marsClassic/de/instance/ko/C-180.xhtml?oid=5538 . Сопоставляется заводская часть VIN, а не конкретный серийный номер. Год выпуска из европейской позиции 10 не угадывается. Это дополнение не означает полного охвата всех Mercedes-Benz.
