# Извлечение диагностики из PDF (веб-версия)

После выбора PDF приложение отправляет файл своему локальному серверу и автоматически извлекает текст через PDF.js. Страницы с менее чем 20 непробельными символами распознаются локальным Tesseract OCR (английский, русский, армянский). Модели OCR находятся в `assets/ocr/`; внешние сервисы распознавания не используются.

Ограничения: PDF до 10 МБ, до 40 страниц, до 500 000 символов; один процесс распознавания одновременно, тайм-аут 120 секунд. PDF с паролем и повреждённые файлы дают понятную ошибку. Ошибка распознавания не удаляет выбранный оригинал: можно повторить обработку или сохранить исходный файл.

Коды и блоки выделяются эвристически из текста, а не из базы неисправностей. Описание берётся из исходного документа; неизвестный блок обозначается явно. Произвольная вёрстка, таблицы и OCR могут потребовать ручной проверки. OCR способен путать `0` и `O`: полный текст можно исправить и нажать «Обновить коды по тексту». Самостоятельные предположения о причинах неисправностей не создаются.

В PDF отчёта включается список «блок / код / описание / страница». Для описания берётся строго текст на той же строке, что код: нижние строки, счётчики и условия появления не присоединяются. Полный текст сохраняется в приложении для проверки и правки, но не печатается в отчёте. Если рядом с кодом нет описания, это явно отмечается.

Описания автоматически переводятся на английский локальными моделями OPUS-MT через Transformers.js. Краткие английские технические фразы сохраняются. Для стандартных терминов применяется словарь переводов фраз; описание никогда не придумывается по номеру кода. Исходное описание сохраняется в `originalDescription`. Перевод не является дополнительной диагностикой и подлежит проверке.

Для установки моделей на новом компьютере:

```powershell
node scripts/setup-translation.mjs opus-mt-ru-en
node scripts/setup-translation.mjs opus-mt-de-en
node scripts/setup-translation.mjs opus-mt-mul-en
```

При работе `allowRemoteModels=false`: текст клиентов не отправляется во внешние службы. Источники моделей: https://huggingface.co/Xenova/opus-mt-ru-en , https://huggingface.co/Xenova/opus-mt-de-en , https://huggingface.co/Xenova/opus-mt-mul-en . Карточки моделей сохранены рядом с файлами. ONNX-веса не включаются в Git.

Оригинальный PDF остаётся доступен отдельно. Перенос кодов в ошибки выполняется кнопкой, с исходным статусом «Требует проверки», без замены существующих ошибок. Исправление распознанного текста не изменяет уже перенесённые ошибки автоматически. Ручные описания ошибок также переводятся при сохранении посещения.

Схема SQLite payload расширена необязательным `diagnosticPdf.analysis`; старые записи и исходные PDF сохраняются. Для ранее загруженного файла доступна кнопка «Распознать PDF».

Проверки: `npm test` проверяет текстовый двухстраничный PDF, привязку DME/DSC/EGS, исключение пробега/VIN/даты, OCR скана, сохранение после перезапуска, правку текста, повторное распознавание и содержание итогового PDF. `npm run test:browser` проверяет загрузку, просмотр таблицы, исправление текста, перенос кодов без дублей, сохранение и экспорт через браузер.

Библиотеки: https://mozilla.github.io/pdf.js/ и https://github.com/naptha/tesseract.js . OCR-модели: https://github.com/tesseract-ocr/tessdata_fast (лицензия сохранена рядом с моделями).
