# Веб-версия BMSPORT YVN

Веб-версия находится в `public/` и `server/`. Нативное приложение iOS находится отдельно в `BMSport/` и `BMSport.xcodeproj/`.

## Запуск

Нужен Node.js 24 или новее.

```sh
npm ci
node scripts/setup-translation.mjs opus-mt-de-en
node scripts/setup-translation.mjs opus-mt-ru-en
node scripts/setup-translation.mjs opus-mt-mul-en
npm start
```

Откройте http://127.0.0.1:3000. В PowerShell при запрете запуска npm.ps1 используйте `npm.cmd` вместо `npm`.

Первичная установка моделей перевода требует интернета и места на диске. Веса ONNX не хранятся в Git. OCR-данные и шрифты с лицензиями входят в `assets/`.

Рабочая база создаётся локально в `data/bmsport.sqlite`. Она содержит посещения и вложения и не включается в Git. Чтобы перенести клиентские данные, используйте отдельную защищённую резервную копию, а не репозиторий исходников.

## Интерфейс

- Русский и английский язык, выбор запоминается в браузере.
- VIN или ручной выбор марки, модели и кузова; справочное фото модели.
- Цветовая тема марки, логотип и доступный слоган.
- PDF диагностики: извлечение текста, OCR, блоки и коды ошибок, перевод описаний на английский.
- Сохранение посещений, история по VIN и экспорт PDF.
- Журнал на мобильном устройстве открывается кнопкой. В журнале можно выбрать модель автомобиля и искать внутри неё.

Переключатель языка меняет интерфейс; существующие правила перевода описаний ошибок и формирования PDF сохраняются.

## Проверки

```sh
node --test
node scripts/browser-check.mjs
node scripts/language-check.mjs
node scripts/vehicle-photo-check.mjs
node scripts/vin-browser-check.mjs
```

Сценарии браузера по умолчанию используют установленный Microsoft Edge. Автономные проверки создают временные базы; `brand-theme-check.mjs` отдельно ожидает работающую локальную веб-версию.

## Временная демонстрация

`node scripts/share-preview.mjs` запускает отдельную демонстрационную базу на 127.0.0.1:3001 с Basic Auth. Пароль генерируется при запуске либо задаётся переменной `BMSPORT_SHARE_PASSWORD`. Путь отдельной базы можно задать через `BMSPORT_SHARE_DB`. Сам по себе этот скрипт не создаёт публичную ссылку. Не публикуйте рабочую базу или пароль в GitHub.

Источники логотипов и слоганов: [BRAND-ASSETS.md](BRAND-ASSETS.md). Источники VIN-каталогов и лицензии находятся в `assets/vin/`.
