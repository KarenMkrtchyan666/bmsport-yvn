# Пробный светлый интерфейс

Вариант: светлая палитра, белые карточки, синие акценты и цвета M в небольшом знаке. Карточка автомобиля с фото находится над вкладками; VIN, марка и модель остаются под изображением в одном ряду на компьютере.

Вкладки: «Посещение», «Диагностика», «История», «Документы». Переключение не сбрасывает несохранённые поля. Если обязательное поле находится в другой вкладке, сохранение открывает нужную вкладку и фокусирует это поле. История показывает только записи с тем же полным VIN, без смешивания разных автомобилей одной модели. Доступно управление вкладками стрелками, Home и End.

## Возврат прежнего вида

Предыдущие HTML, CSS, код формы и изменённые сценарии проверки сохранены в `.ui-backups/`. Текущая контрольная копия указана в `.ui-backups/current.json`. Целостность копий подтверждена SHA-256; возврат проверен в отдельной временной папке.

Проверить копию:

```powershell
node scripts/restore-ui.mjs --check
```

Вернуть старый интерфейс:

```powershell
node scripts/restore-ui.mjs
```

Затем обновить браузер. Откат восстанавливает внешний вид и поведение формы, не удаляя данные клиентов, посещений и прикреплённые PDF. Сервер и доступ по временной ссылке продолжают работать.

Проверки нового вида: `npm run test:browser`, `node scripts/vin-browser-check.mjs`, `node scripts/vehicle-photo-check.mjs --live`, `node scripts/premium-ui-check.mjs`.
