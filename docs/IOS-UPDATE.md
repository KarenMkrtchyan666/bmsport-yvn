# Нативная iOS-версия: обновление

Минимальная версия остаётся iOS 17. Приложение использует SwiftUI, SwiftData, PDFKit, Vision и Core Text; WebView не используется.

## Перенесённые функции

- Выбор марки и модели с поиском; вложенные кузова BMW в одном выборе модели.
- Локальный VIN-каталог BMW/MINI/Rolls-Royce, подтверждённый заводской тип Mercedes и поиск по собственным сохранённым посещениям. Неизвестный VIN не объявляется неверным: модель выбирается вручную.
- Фотографии по марке и модели после ручного выбора или VIN, логотипы, слоганы и спокойный градиент бренда. Фото включаются отдельным переключателем; VIN и поля клиента не отправляются.
- Импорт исходного PDF до 10 МБ / 40 страниц, извлечение текста и локальный OCR сканов через Vision. Ошибка включает блок, код и описание из той же строки; нижние служебные строки не включаются в описание.
- Исходный PDF сохраняется в защищённой папке Application Support/DiagnosticAttachments. Текст сохраняется в отчёте, доступен для проверки и исправления. В экспортируемый отчёт попадают структурированные ошибки, а не вложенный диагностический PDF.
- Локальный системный перевод на английский через Translation на iOS 18+. Система может запросить загрузку языков. Первый поддерживаемый язык определяется автоматически; для другого языка диагностики используйте выбор и кнопку перевода. Список предлагает немецкий, русский, французский, итальянский и испанский; доступность зависит от системы. На iOS 17 описания проверяются и правятся вручную.
- Русский и английский интерфейс, фильтр истории по модели, тёмное оформление. Содержимое клиентских полей не переводится переключателем интерфейса.

## Совместимость и ограничения

Новые свойства ReportData и Fault — необязательные Codable-поля. Старые JSON payload и SwiftData-модель не заменяются; ошибка чтения по-прежнему видна, данные не сбрасываются. Подготовлен тест чтения старого payload без новых ключей.

Нативная версия намеренно не посылает VIN в сторонние онлайн-базы. Это ограничивает покрытие по сравнению с веб-версией и сохраняет правило проекта о клиентских данных. Сетевое фото справочное: неподтверждённый кузов не выдаётся за точное совпадение. При отсутствии фото сам отчёт остаётся доступен.

Снятие PDF с отчёта не удаляет файл безвозвратно: это защищает предыдущие черновики и восстановительные записи. Резервная копия должна включать и SwiftData/Recovery, и DiagnosticAttachments. Миграция данных из веб-версии автоматически не выполняется.

## Сборка и проверки

Откройте BMSport.xcodeproj на Mac с Xcode 16+, выберите Apple Team и уникальный Bundle Identifier. Используйте схему BMSport. Приложение можно собирать для iOS 17; Translation включается только на iOS 18+.

В GitHub добавлен workflow Native iOS tests для сборки и unit/UI-тестов на симуляторе. Результат конкретного запуска нужно смотреть во вкладке Actions; наличие workflow само по себе не означает успешную сборку.

Проверка коммита `9fa6bbd` успешно завершена на Mac/Xcode 16.4 и симуляторе iPhone 16 Pro / iOS 18.5: 8 unit-тестов и 2 UI-теста. Проверены JSON-совместимость, сохранение после повторного открытия, обработка повреждённого payload, VIN-каталоги, INPA/строки кодов, многостраничный Unicode PDF, создание/поиск/открытие отчёта и Share Sheet. [Журнал запуска](https://github.com/KarenMkrtchyan666/bmsport-yvn/actions/runs/40318965363). Системный перевод с загрузкой языков, импорт сканов Vision и внешний вид на физическом iPhone по-прежнему требуют ручной проверки.

На Windows выполняются только подготовка ресурсов и структурные проверки. Локальная Xcode-сборка и физический iPhone здесь недоступны. Перед использованием клиентами обязательны ручная проверка многостраничного PDF с русским и армянским текстом, Share Sheet, импорт скана, системный перевод и сохранение после перезапуска на физическом iPhone. Подписанный IPA и установка на устройство в GitHub-архив исходников не входят.

Обновление ресурсов: `node scripts/prepare-ios-resources.mjs`, `node scripts/prepare-ios-localization.mjs`, затем `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Generate-Project.ps1`.
