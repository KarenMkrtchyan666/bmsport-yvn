# Фотография модели после определения VIN

После успешного определения автомобиля над формой отображается карточка: фотография модели, название, тип кузова и доступный модельный год. При открытии сохранённого посещения фото подбирается повторно по известной модели. Смена VIN или ручная правка автомобиля убирает старую фотографию; запоздавшие ответы не применяются.

Это справочная фотография модели, а не фотография конкретного экземпляра или подтверждение его окраски/комплектации. Карточка содержит соответствующую подпись. Если известен заводской код кузова, метаданные изображения должны явно содержать этот код; общая фотография другой модели не подставляется. Для BMW используются запросы вида `3 Series (E46)`, затем код кузова.

Бесплатный источник: [carapi.trustcar.info](https://carapi.trustcar.info/), [открытая документация](https://github.com/trustcarinfo/carapi). Источник подбирает фотографии Wikidata/Wikimedia Commons. Автор, лицензия и атрибуция отображаются под фото со ссылкой на запись Wikidata. У самих фотографий собственные лицензии, включая CC BY/CC BY-SA и Public domain; лицензия кода API не заменяет лицензию изображения.

`POST /api/vehicle/image` принимает только марку, модель, код кузова и необязательный год. VIN, имя клиента, PDF и заметки для поиска фото не отправляются. Внешние URL изображений ограничены HTTPS и доверенными хостами провайдера/Wikimedia. HTML из авторских метаданных не исполняется.

Положительные результаты кешируются в памяти на 24 часа, подтверждённое отсутствие фотографии — на час, максимум 500 записей. Ошибки сети не кешируются как отсутствие изображения. Изображения загружаются напрямую с CDN с `referrerpolicy=no-referrer`; приложение не хранит их копии. Нет обязательного ключа или платной подписки. Недоступность фото не препятствует заполнению и сохранению посещения; есть повторная загрузка.

Проверки: `npm test`, `node scripts/vehicle-photo-check.mjs`, `node scripts/vehicle-photo-check.mjs --live`. Проверены карточка на компьютере/мобильном экране, живое фото W203, сохранённые посещения, исчезновение устаревшего изображения и ошибки источника. VIN в тестах имеют искусственные серийные части. Фотографии в PDF не добавляются этой функцией.
